# ReceiptHub v1.15.0 ご利用代金明細照合ルール

## 通常照合

通常の直接領収書照合、返金書類内の元決済、明示的な返金相殺、同一請求元内の近接返金相殺を先に実行する。通常照合で一致した明細は契約変更推定の対象にしない。

## 契約変更推定

通常照合後に未一致となった明細について、次をすべて確認する。

1. 契約変更書類の請求元グループと明細の請求元グループが一致する。
2. 契約変更書類に旧プラン名と旧プラン終了日が明記される。
3. 明細利用日が旧プラン終了日の±1日以内である。
4. 契約変更情報の信頼度が0.75以上である。
5. Bill toメールがReceiptHubの一般ユーザーへ一意に一致する。メールを確認できない場合は領収書の登録ユーザーを使用する。
6. 過去領収書がある場合は、同一ユーザー、同一請求元、前月、金額・通貨完全一致、請求日±1日を満たす。
7. 過去領収書を利用できない場合は、前月カード明細の同一請求元、前月、金額・通貨完全一致、請求日±1日を補助証拠として利用できる。
8. 金額に許容差を設けない。
9. 契約変更書類と過去証拠を複数の明細へ重複使用しない。

前月カード明細を使う場合は、領収書提出を証明していないため信頼度を下げ、必ず管理者確認前の`推定対応`とする。
