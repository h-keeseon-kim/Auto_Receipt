# ReceiptHub v1.15.4 全社明細と領収書発行月の対応

## 月次ルール

```text
ご利用代金明細月 M
= 照合する領収書発行月 M
= 内部提出サイクル M+1 に保存された領収書
```

例：

```text
2026年07月分の全社明細
→ 領収書発行月 2026年07月
→ 内部提出サイクル 2026年08月の全ユーザー領収書
```

## 再照合

既存明細にはマイグレーション0037で再照合マーカーを付けます。明細PDFをOpenAIへ再送信せず、保存済み明細行と新しい対象月の領収書で再照合します。

## 領収書更新時

領収書が内部提出サイクルM+1へ追加・差し替え・再解析された場合、領収書発行月Mの全社明細だけを再照合待ちにします。アップロード要求中には再照合を同期実行しません。
