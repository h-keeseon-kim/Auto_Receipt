# ReceiptHub v1.16.1 最終運用フロー追補

## ご利用代金明細の照合

1. 選択した明細月の保存済み明細行を読み込む。
2. 明細内の実利用月から、当月と前月等の必要な領収書候補を取得する。
3. 直接一致、返金書内元決済、返金相殺、返品元参照、契約変更推定を実行する。
4. 未使用一覧の表示対象を、PDF本文の日付が選択月に属する書類と、実明細に請求元・日付で関連する月跨ぎ書類へ絞る。
5. 照合候補として読み込んだだけの無関係な過去月PDFは、「明細に紐づかなかった提出書類」へ表示しない。
6. 日付を抽出できない当月提出PDFは、解析不足を隠さないため表示対象に残す。

## デプロイ後

`python manage.py migrate`で`0040_unmatched_receipt_event_scope`を適用する。既存明細には再照合マーカーが付与され、管理者が対象月のご利用代金明細ページを開くと、保存済み明細行と最新の領収書メタデータだけで再照合される。明細PDFをOpenAIへ再送信する必要はない。
